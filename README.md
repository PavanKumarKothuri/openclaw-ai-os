# OpenClaw AI OS

A personal AI operating system built using OpenClaw.

## Mission

Build, operate and evaluate a reliable AI workforce using autonomous agents.

## Core capabilities

- Multi-model support: OpenAI and Google Gemini
- Agent skills and persistent memory
- Tools and MCP integrations
- Human approval and permission controls
- Logging and observability
- Agent evaluation and reliability testing

## Development principles

1. Build before theorising.
2. Human approval for sensitive actions.
3. Measure reliability, latency and cost.
4. Keep credentials and private data out of source control.
5. Document every working capability.

## Roadmap

- Month 1: OpenClaw AI OS
- Month 2: AI Operations Agent
- Month 3: Autonomous Research Agent
- Month 4: AI Mission Control
- Month 5: Agent Evaluation Lab
- Month 6: Intelligent AI Workforce
